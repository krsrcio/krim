# krim

Personal portfolio for Kristine Castres, focused on software, mobile, and game development work.

## Scripts

- `npm install` installs the project dependencies.
- `npm run dev` starts the Vite development server.
- `npm run lint` runs ESLint across the app.
- `npm run typecheck` runs TypeScript in build mode.
- `npm run build` runs typecheck and creates a production build.
